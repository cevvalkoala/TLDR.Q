TLDR / SETTINGS

Make it yours.

Choose where summaries are generated and how they sound.

01 / CONNECTION

Model provider

Connect to the service you want to use. Summaries send the captured page title and text to your selected provider.

Enter a specific API URL without wildcards. Remote services require HTTPS; HTTP is allowed only on loopback. Host permissions may cover all ports on a host.

Your key is stored unencrypted in your browser profile and is not synced. When a key is configured, it is sent to your selected provider for model discovery and summaries. Firefox requests optional permission to transmit authentication information when you save or load models; you can revoke it in about:addons under Permissions and data. Keyless Ollama does not need this permission.

Enter a model name, or load suggestions from your provider.

02 / INSTRUCTIONS

Summary prompt

Set the instructions sent with each page.

Use the default prompt or write your own.

03 / SHORTCUT

Keyboard shortcut

Open TLDR without reaching for the toolbar.

Focus the box and press a shortcut, then select Update. Tab moves focus and Escape stops recording. Some shortcuts are reserved by the browser or operating system.

In Chrome, open chrome://extensions/shortcuts to change the TLDR shortcut. The default is Alt+Shift+Q.

04 / DATA

Delete saved summaries

Remove existing summaries and cancel pending requests. Your settings will remain.
